# e.c. 指数3群の中心は有限商で検出できない

2026-09-22。第6節 Question 6.2 の検討における、候補となる証明経路の除外である。
以下は本ノートで詳述する通常の数学的証明であり、Lean ではまだ形式化していない。
Question 6.2 や Takeuchi 予想の解決を主張するものではない。

## 命題

`M` を、通常の群言語における指数3の群の類 `V₃` の e.c. 群とする。
有限 residual を

\[
 R_{\mathrm{fin}}(M)
 =\bigcap_{\substack{Q\ \mathrm{finite}\\f:M\to Q\ \mathrm{homomorphism}}}\ker f
\]

と定める。これは有限指数正規部分群すべての共通部分と等しい。このとき

\[
  1\ne Z(M)\le R_{\mathrm{fin}}(M).
\]

従って `M` は残余有限ではない。この主張は、各有限生成自由指数3群が有限、従って
残余有限であることと矛盾しない。

## 1. 使用する有限群の明示的な構成

`n ≥ 1` とし、`k = 𝔽₃`、`W = kⁿ` とする。
集合 `Hₙ = W × W × k` に積

\[
 (u,v,t)(u',v',t')
   =(u+u',\ v+v',\ t+t'+u\cdot v')
\]

を入れる。ここで `u · v' = Σᵢ uᵢv'ᵢ` は標準内積である。
双線形性により積は結合的で、単位元は `(0,0,0)`、逆元は
`(u,v,t)⁻¹ = (-u,-v,-t+u·v)` となる。
また

\[
 (u,v,t)^3=(0,0,3t+3u\cdot v)=(0,0,0),
\]

なので `Hₙ ∈ V₃` である。交換子を `[x,y]=xyx⁻¹y⁻¹` とすると、直接計算により

\[
 [(u,v,t),(u',v',t')]=(0,0,u\cdot v'-u'\cdot v).
\]

標準基底を `eᵢ` とし、`xᵢ=(eᵢ,0,0)`、`yᵢ=(0,eᵢ,0)`、`z=(0,0,1)` と置く。
すると `z` の位数は3で、

\[
 [x_i,x_j]=[y_i,y_j]=1,\qquad
 [x_i,y_j]=z^{\delta_{ij}},\qquad z\in Z(H_n).
\]

任意の `(u,v,t)` は

\[
 \left(\prod_i x_i^{u_i}\right)
 \left(\prod_i y_i^{v_i}\right)z^{\,t-u\cdot v}
\]

と表される。指数は `k` の元を `0,1,2` で代表して解釈する。
従って `|Hₙ|=3^(2n+1)`。交換子の式から中心は `{(0,0,t):t∈k}=⟨z⟩` で、
`n ≥ 1` では交換子部分群も `⟨z⟩` となる。
この具体的な Heisenberg 群が、ここで使う extraspecial 群である。
以下の証明は extraspecial 群の分類を必要としない。

## 2. 中心元を指定した central product

`1 ≠ a ∈ Z(M)` を固定する。指数3なので `a` の位数はちょうど3である。
`M × Hₙ` の中心部分群

\[
 C=\langle(a,z^{-1})\rangle
   =\{(a^j,z^{-j}):j=0,1,2\}
\]

を取り、`Kₙ=(M×Hₙ)/C` と置く。
直積と商は指数3を保つので `Kₙ ∈ V₃` である。

写像 `i:M→Kₙ`、`g↦(g,1)C` は単射である。
実際、`(g,1)=(a^j,z^{-j})` なら `z^j=1`、従って `j=0 mod 3`、`g=1` となる。
同様に `Hₙ→Kₙ`、`h↦(1,h)C` も単射である。
後者では `a` の位数が3であることを使う。
商では `(a,1)C=(1,z)C` なので、`z` は指定した `a` と同一視される。

## 3. e.c. 性から得られる有限個の方程式の解

`Kₙ` 内の `xᵢ,yᵢ` の像は、パラメータ `i(a)` を用いる有限連立方程式

\[
 [u_i,u_j]=1,\quad [v_i,v_j]=1,\quad
 [u_i,v_j]=
 \begin{cases}i(a)&i=j,\\1&i\ne j\end{cases}
 \qquad (i,j<n)
\]

の解である。`M` は `i` により `Kₙ` の部分群と同一視でき、e.c. 性により同じ連立方程式は
パラメータ `a` を用いて `M` 自身で解を持つ。その解を `uᵢ,vᵢ ∈ M` と書く。

ここで「新しい元が `M` のすべての元と可換」という無限個の条件を e.c. 性で移したわけではない。
移しているのは上に表示した有限個の方程式だけである。
後で必要になる `a` と解の可換性は、もともとの仮定 `a∈Z(M)` から従う。
`a≠1` も固定したパラメータ自身の性質である。

## 4. 有限像の中での単射性と位数下界

有限群への準同型 `f:M→Q` を取り、`A=f(a)≠1` と仮定する。
`A` の位数は3であり、`A` は `f(M)` の中心に属する。
`Uᵢ=f(uᵢ)`、`Vᵢ=f(vᵢ)` は同じ交換子関係を満たす。
これらが生成する部分群 `S` の交換子は中心部分群 `⟨A⟩` に入る。

関係式を使って任意の語を整理すると

\[
 \prod_{i<n} U_i^{r_i}\prod_{i<n}V_i^{s_i} A^t
 \qquad(r_i,s_i,t\in\{0,1,2\})
\]

の形になる。この形の語が単位元であるとする。
両辺と `Vⱼ` との交換子を取ると `A^{rⱼ}=1`、従って `rⱼ=0` となる。
同様に `Uⱼ` との交換子を取ると `A^{-sⱼ}=1`、従って `sⱼ=0` となる。
最後に `A^t=1` から `t=0` である。
同じ計算を二つの語が等しい場合に適用すると、すべての指数が一致する。
したがって表示した `3^(2n+1)` 個の語は相異なり、

\[
 |Q|\ge |S|=3^{2n+1}.
\]

これは、上記の座標表示に従う写像 `Hₙ→S` が単射であることも証明している。
従って「中心元 `z` を殺さない準同型は `Hₙ` 上で単射」という性質を、
有限 extraspecial 群に関する外部定理として仮定する必要はない。

`n` は任意なので、`3^(2n+1)>|Q|` となる `n` を選ぶと矛盾する。
従って `f(a)=1`。これは任意の有限群 `Q` と準同型 `f` について成り立つので
`a∈R_fin(M)` である。`a=1` の場合は自明であり、`Z(M)≤R_fin(M)` を得る。

## 5. 中心が非自明であること

自由指数3群 `F₃` には、基本三重交換子 `[s,x,y]≠1` が存在する。
`M×F₃` は指数3群で `M` を含むから、文

\[
 \exists b,c,d\;[b,c,d]\ne1
\]

はこの拡大で真である。e.c. 性から `M` 内でも真となる。
指数3群では三重交換子は中心に属するので、これが非自明な中心元を与える。

この二つの既知の群論入力は、原稿 v7 の Levi–van der Waerden の正規形および
指数3群の class が高々3であることに対応する。リポジトリでは例えば
[Free/ModelComparison.lean](../T3/GroupTheory/Free/ModelComparison.lean) の
`T3.Free.triple_commutator_of_ne_one` と、
[Identities.lean](../T3/GroupTheory/Identities.lean) の中心性の諸結果で扱われている。
本ノートで新たに使った central product と有限 residual の議論は未Lean化である。

## 6. 非自明な有限 absolute retract は存在しない

`E ∈ V₃` が **absolute retract** であるとは、任意の埋め込み `i:E→G`、`G∈V₃` に対し、
準同型 `r:G→E` で `r∘i=id_E` となるものが存在することをいう。
この定義のもとで、`V₃` の非自明な有限群は一つも absolute retract ではない。

実際、非自明な有限指数3群 `E` を取る。Cauchy の定理より `|E|` は3の冪であり、
有限3群の中心は非自明なので、`1≠a∈Z(E)` を取れる。この `a` の位数は3である。
`3^(2n+1)>|E|` となる `n≥1` を選び、上と同じ構成で

\[
 G=(E\times H_n)/\langle(a,z^{-1})\rangle
\]

を作る。§2 の計算により、`G∈V₃` であり、自然な写像 `i:E→G` と `j:Hₙ→G` は
ともに単射、かつ `i(a)=j(z)` である。

もし retraction `r:G→E` が存在すれば、準同型 `h=r∘j:Hₙ→E` は
`h(z)=r(i(a))=a≠1` を満たす。§4 の交換子による係数の抽出を `h(xᵢ),h(yᵢ),a`
に適用すると、`h` は単射になる。従って

\[
 3^{2n+1}=|H_n|\le |E|,
\]

となり、`n` の選び方と矛盾する。ここでは e.c. 性を一切使っていない。
また `G` 自体も有限なので、`E` は有限な `V₃`-拡大だけに限定しても absolute retract
ではない。自明群は常に retraction を持ち、この例外は必要である。

従って、他の variety で有効な「有限集合を有限 absolute retract に含める」という方針は、
局所有限性と model companion の存在だけを仮定して一般化できない。
指数3の e.c. 群にも、非自明な有限集合を含む有限 `V₃`-absolute-retract 部分群は存在しない。
この結論は Question 6.1 に対する否定解ではなく、一つの十分条件・証明手段を除外する。

## 7. Question 6.2 への意味と限界

指数3群の variety は局所有限で、今回の主定理により model companion を持つ。
それにもかかわらず、その e.c. モデルは上の命題により残余有限ではない。
従って次の二つの一般化は、すでにこの肯定例で成り立たない。

- 局所有限な群はすべて残余有限である。
- 有界指数の群 variety に model companion があれば、その e.c. モデルは残余有限である。

局所有限性は各有限生成部分群が有限であることを意味する。
その有限部分群を分離する準同型が群全体から有限群へ延長できることは意味しない。
上の中心元は有限部分群の中では非自明だが、群全体のどの有限商でも消える。

一方、[第6節の整理](section-six-analysis.md) の RBP による還元が必要とするのは、
**各有限 rank の相対自由群 `F_V(r)` の残余有限性**である。
e.c. モデル全体の残余有限性はこれより強い別の要求であり、今回の否定例によって
相対自由群の残余有限性や Question 6.2 自体が否定されたわけではない。

この命題の証明は上に全て記した。関連する一次文献として、
[d'Elbée–Müller–Ramsey–Siniora, §3 および Corollary 4.42](https://arxiv.org/html/2310.17595v3)
には、奇素数の class 2 群の双線形形式による記述と model companion の結果がある。
同論文の一般 `c` に関する群の結果は `c<p` を仮定し、`p=c=3` の場合の根拠としては用いない。
本ノートの `T₃` への適用は、リポジトリの指数3に関する既知の結果と上述の直接構成に基づく。
